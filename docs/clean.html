What it does

Seven cleanups, each optional

1

Scan with counts

See how many items each cleanup would touch before you change anything.

2

Whole model or selection

Select groups to clean only those (nested ones included). Select nothing to clean everything.

3

One undo step

All cleanup runs as a single operation. If you do not like it, Ctrl+Z.

Pick what to clean

Tick the cleanups you want. Counts update when the selection changes.

  • Stray edges (curves and arcs can be kept)
  • Coplanar edges that split a flat face
  • Faces painted only on the back are flipped
  • Empty groups and components
  • Unused components, materials and tags

Good to know

What it does and does not do

It does

  • Works on the active model, one undo step
  • Keeps edges that belong to a face
  • Keeps soft and smooth edges
  • Keeps curves and arcs unless you untick the option

It does not

  • Does not repair open meshes or fill holes
  • Does not merge duplicate geometry
  • Does not touch hidden tags or layers that are in use
  • The counts for unused materials can be lower than the final result, because items used only by unused components are freed after those are removed
FAQ

Questions

Is it free?

Yes. PANORAMA Clean is free, with no licence key.

Will it break my model?

Cleaning is one undo step. Save a copy before the first run on an important file.

Which SketchUp versions?

SketchUp 2022 and newer, Windows and macOS. It has been tested on Windows with SketchUp 2026; macOS is untested.
