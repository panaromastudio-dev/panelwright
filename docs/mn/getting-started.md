# Эхлэх

## Суулгах

1. `Panelwright.rbz` файлыг татна.
2. SketchUp дотор: **Extensions → Extension Manager → Install Extension** гэж орж файлаа сонгоно.
3. Шинэ цэс гарч ирнэ: **Extensions → Panelwright**.

**macOS:** SketchUp "тодорхойгүй хөгжүүлэгчээс" гэж анхааруулбал *Extension Manager* нээж, өргөтгөлөө дараад *Enable* гэж сонгоно. Өргөтгөл нь Trimble-ийн дижитал гарын үсэгтэй.

## Идэвхжүүлэх

**Extensions → Panelwright → 🔑 Лиценз / Идэвхжүүлэх.**

- **Туршилт:** *Туршилт эхлэх* дарна — 10 хоног, бүх боломж нээлттэй.
- **Лицензтэй:** түлхүүрээ буулгаад *Идэвхжүүлэх* дарна. Түлхүүр энэ компьютерт холбогдоно. Өөр компьютер рүү шилжүүлэх бол эхлээд эндээс идэвхгүй болгоод, дараа нь тэнд идэвхжүүлнэ.

## Хэл болон нэгжээ сонгох

**Extensions → Panelwright → Хэл / Language** — English, Español, Türkçe, Русский, 中文, Монгол.

Нэгжийг үндсэн цонхноос тохируулна: **Нарийн тохиргоо → Нэгж** — *Миллиметр*, *Инч — фракцаар*, эсвэл *Моделийн нэгжийг дагах*. Дотроо бүх тооцоо миллиметрээр явагддаг, нэгж нь зөвхөн харагдах болон оруулах хэлбэрийг өөрчилнө.

## Үндсэн цонх

**Extensions → Panelwright → Задаргаа, Nesting, Өртөг** гэж орвол зүүн талдаа табтай цонх нээгдэнэ:

| Таб | Юунд хэрэгтэй |
|---|---|
| **Үр дүн** | Тооцоолох, задаргааны жагсаалт, хавтангийн зураглал, өртгийн задаргаа. Эндээс эхэлнэ. |
| **Тавилга үүсгэх** | Параметртэй шүүгээ, бүтэн гал тогооны эгнээ. |
| **Төсөл ба харилцагч** | Таны компани, захиалагч, төслийн код, нөхцөл. Бүх баримт бичигт автоматаар орно. |
| **Үнэ ба тариф** | Хавтан материал (ширхэгээр), зүсэлт, ирмэг хуулга, тоноглол, ажлын хөлс, тээвэр, ашгийн хувь, татвар. |
| **Тоноглол** | Моделиос тоолсон бүх тоноглол ба каталог. |
| **Нөөц / Агуулах** | Агуулахад байгаа хавтан, тоноглол, доод хэмжээ, үлдэгдэл. |
| **Ашиг** | Төсөл бүрийн төлөвлөсөн ба бодит ашгийн харьцуулалт. |
| **Нөөцлөлт** | Бүх тохиргоо, үнийг экспорт / импорт хийх. |
| **Туслах** | Суурилуулсан гарын авлага. |

Дээд талын мөрөнд **Тооцоолох** болон экспортын товчнууд байна. **Нарийн тохиргоо** (баруун дээд) хэсэгт зүсвэрийн зузаан, ашгийн хувь, ирмэг хуулгын дүрэм, дугаарлалт, DXF сонголт, нэгж, цаасны хэмжээ байна.

## Анхны тооцоо

1. **Төсөл ба харилцагч** → компанийн нэрээ оруулаад **Хадгалах** дарна. Энэ нэр бүх PDF дээр гарна.
2. **Тавилга үүсгэх** → *Доод шүүгээ* → өргөн 600, өндөр 720, гүн 560, 1 хаалга, 1 тавиур → **3D загварт үүсгэх**.
3. Үүнийг 800 өргөнтэй *Дээд шүүгээ*, 3 шургуулгатай 500 өргөнтэй *Шургуулгын шүүгээ*-ээр давтана.
4. **Үр дүн** → **Тооцоолох**.

Одоо танд задаргааны жагсаалт (мөр дээр дарвал деталь 3D-д гарна), ашиглалтын хувьтай хавтангийн зураглал, тоноглолын жагсаалт, бүрэн өртөг бэлэн боллоо.

5. **Үнийн санал (PDF)** дарна. Засварлагч дээр бүх мөр харагдана — хүсвэл засаад, задаргааны хэлбэрээ сонгоод **Экспорт** дарна.

## Өөрийн тавилгаа загварчлах

Өргөтгөл нь **групп болон компонент**-ыг деталь гэж тоолдог. Сайн ажиллуулах дүрмүүд:

- Хавтан бүр өөрийн групп эсвэл компонент байна. 3–60 мм зузаантай хавтанг хавтангийн деталь гэж үзэх бөгөөд түүнээс жижиг зүйлийг тоноглол гэж үзнэ.
- Нэр чухал: *Door*, *Дверца*, *Хаалга* гэж нэрлэсэн групп нь урд хавтан гэж тооцогдоно (дөрвөн талд нь ирмэг хуулах, nesting дээр эргэхгүй). *hinge*, *slide*, *handle* гэсэн нэртэй зүйл тоноглол болно.
- Шүүгээ бүрийг өөрийн гадна групп дотор байрлуулна. Гадна группийн нэр нь шүүгээ тус бүрийн өртгийн задаргаанд шүүгээний нэр болно.
- Бүс: хамгийн гадна группээ *Kitchen*, *Wardrobe* гэх мэтээр нэрлэх, эсвэл ямар ч группийн нэрэнд `[Z:Kitchen]` нэмбэл өрөө бүрийн нийт дүн гарна.
- Материалын нэр **Үнэ ба тариф → Хавтан материал** дахь нэртэй таарах ёстой — ингэж л хавтан бүр үнэ болон хавтангийн хэмжээгээ авна.
