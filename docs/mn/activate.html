Лицензийн түлхүүрээ аваарай

Таны түлхүүр нэг компьютерт холбогддог тул төлбөр хийх үед биш, суулгасны дараа үүсдэг. Ойролцоогоор нэг секунд болно.

  1. Panelwright-ийг суулгана — .rbz файл захиалгын и-мэйлтэй хамт ирсэн. SketchUp дотор: Extensions → Extension Manager → Install Extension.
  2. Extensions → Panelwright → Лиценз хэсгийг нээгээд, тэнд харагдах Computer ID-г хуулна.
  3. Хоёуланг доор буулгана. Түлхүүр энэ хуудсан дээр гарч ирнэ — тэр Лиценз цонхонд оруулна.
Худалдан авалтын и-мэйлээс — 2C4A1B9E-7F3D-4A21-B8C6-9E1D5F0A3C7B шиг харагдана.
SketchUp доторх Extensions → Panelwright → Лиценз хэсгээс.

Компьютер солих уу? Шинэ компьютер дээр ижил хуудсыг ашиглана. Суудал бүгд дүүрсэн бол support@panelwright.app руу бичнэ үү, хуучин нь чөлөөлөгдөнө. Түлхүүрээ гээсэн үү? Ижил хоёр утгаа дахин оруул — ижил түлхүүр буцаж гарна, нэмэлт суудал зарцуулахгүй.
