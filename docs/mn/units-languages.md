# Нэгж ба хэл

## Нэгж

**Нарийн тохиргоо → Нэгж**

| Сонголт | Юу харагдах вэ |
|---|---|
| **Миллиметр** | `720 × 560`, `16` |
| **Инч — фракцаар** | `28 3/8 × 22 1/16`, `5/8` |
| **Моделийн нэгжийг дагах** | SketchUp-ийн модельд тохируулсан нэгж |

**Фракцын нарийвчлал** (зөвхөн инчид): 1/8, 1/16, 1/32 эсвэл 1/64. Тавилгын үйлдвэрлэлд ихэвчлэн 1/16 хэрэглэнэ.

### Утга оруулах

Урттай талбар бүр дараахыг хүлээн авна:

| Та бичих нь | Ойлгогдох нь |
|---|---|
| `560` | одоогийн нэгжээр 560 |
| `22 1/16` эсвэл `22-1/16` | 22 1/16 инч |
| `3/4"` эсвэл `0.75in` | 3/4 инч (тодорхой) |
| `1' 10 1/2"` эсвэл `1ft 6in` | фут + инч |
| `1200mm`, `2.5cm`, `1.22m` | метрийн (тодорхой) |

Тодорхой бичсэн нэгж одоогийн горимоос үргэлж давуу тул инчийн горимд ч `1200mm` нь 1200 мм байна. Танигдаагүй текст бичвэл талбар өөрчлөгдөхгүй.

### Юу нь метрээр хэвээр үлдэх вэ

- **DXF файл** үргэлж миллиметрээр — CNC болон зүсэгч програмууд ингэж хүлээдэг.
- **Дотоод тооцоо** үргэлж миллиметрээр. Нэгж солих нь үр дүнг хэзээ ч өөрчлөхгүй, зөвхөн харагдах хэлбэрийг өөрчилнө.

### Хавтангийн хэмжээ

**Үнэ ба тариф → Хавтан материал → Формат** дахь бэлэн сонголтууд:

| | |
|---|---|
| 2800 × 2070 мм | Орос, Монгол, Хятад |
| 2500 × 1250 мм | Европ |
| 2440 × 1220 мм | метрийн "8 × 4" |
| **8' × 4'** (2438.4 × 1219.2) | АНУ, Канад — яг |
| 10' × 4', 8' × 5' | АНУ |

Метрийн 2440 × 1220 нь 96 × 48 инчтэй **яг тэнцэхгүй** (96 1/16) гэдгийг анхаарна уу. Бодитоор худалдаж авдгаа сонгоно.

## Хэл

**Extensions → Panelwright → Хэл / Language**

English · Español · Türkçe · Русский · 中文 · Монгол

Бүх интерфейс, бүх PDF, Excel, CSV болон DXF-ийн шошго хэлийг дагана. Таны өөрөө бичсэн зүйл (компанийн нэр, материалын нэр, тэмдэглэл) бичсэн хэвээрээ үлдэнэ.

Гэрээ болон и-мэйлийн загвар: Монгол хэлэнд Монгол загвар, бусад бүх хэлэнд Англи загвар хэрэглэгдэнэ.

**Хятад PDF** нь Англиар гарна, учир нь PDF-д шингээсэн фонт CJK тэмдэгтгүй. Интерфейс өөрөө бүрэн хятад хэлтэй.

### Орчуулга нэмэх эсвэл засах

*Extensions → Panelwright → Хэл / Language → Орчуулгын файл экспортлох* нь засаж болох JSON файл бичнэ. Үүнийг өргөтгөлийн фолдерт буцаан тавивал суурилуулсан текстийг дарж бичнэ. Бидэнд илгээвэл дараагийн хувилбарт оруулна.
