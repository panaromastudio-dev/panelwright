Тоотой шалгалт

Бүх модель эсвэл сонголт

Групп сонговол зөвхөн тэр (дотор нь орсон ч) цэвэрлэгдэнэ. Юу ч сонгоогүй бол бүгдийг.

3

Нэг алхамд буцаана

Бүх цэвэрлэгээ нэг үйлдэл. Таалагдахгүй бол Ctrl+Z.

Юуг цэвэрлэхээ сонго

Хэрэгтэй цэвэрлэгээгээ чагтална. Сонголт өөрчлөгдөхөд тоо шинэчлэгдэнэ.

  • Илүү шугам (нум, муруйг хадгалах боломжтой)
  • Хавтгай талыг хуваасан нэг хавтгайн шугам
  • Зөвхөн ар талдаа будагдсан талыг эргүүлнэ
  • Хоосон групп, компонент
  • Ашиглаагүй компонент, материал, tag

Хийдэг

  • Идэвхтэй моделиор ажиллана, нэг алхамд буцаана
  • Талд хамаарах шугамыг хэвээр үлдээнэ
  • Зөөлрүүлсэн (soft/smooth) шугамыг хөндөхгүй
  • Сонголтыг авахгүй бол нум, муруйг хэвээр үлдээнэ

Хийдэггүй

  • Нээлттэй мэш засахгүй, нүх нөхөхгүй
  • Давхардсан геометрийг нэгтгэхгүй
  • Ашиглагдаж буй tag/layer-д хүрэхгүй
  • Ашиглаагүй материалын тоо эцсийн үр дүнгээс бага гарч болно: зөвхөн ашиглаагүй компонентод орсон материал тэдгээрийг устгасны дараа чөлөөлөгдөнө

Түгээмэл асуулт

Үнэгүй юу?

Тийм. PANORAMA Clean үнэгүй, лицензийн түлхүүр шаардахгүй.

Моделийг эвдэх үү?

Цэвэрлэгээ нэг алхамд буцна. Чухал файл дээр анх ажиллуулахаасаа өмнө хуулбар хадгал.

Аль SketchUp хувилбар?

SketchUp 2022 ба түүнээс шинэ, Windows болон macOS. Windows дээр SketchUp 2026-аар шалгасан; macOS шалгаагүй.

Бусад үнэгүй нэмэлт

PANORAMA Shape: тавилгыг ухаалгаар сунгах, мөн fillet, chamfer.
