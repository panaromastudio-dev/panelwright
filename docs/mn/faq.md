# Түгээмэл асуулт

**Миний моделийн нэг деталь задаргааны жагсаалтад ороогүй байна.**
Энэ нь групп эсвэл компонент мөн эсэх (чөлөөт гадаргууг тооцохгүй), зузаан нь Нарийн тохиргоо дахь *Хамгийн бага* ба *Хамгийн их зузаан*-ын хооронд (анхдагч 3–60 мм) байгаа эсэх, нүүрний талбай *Хамгийн бага талбай*-аас (анхдагч 3000 мм² — түүнээс жижиг зүйлийг тоноглол гэж үзнэ) их эсэхийг шалгана. Үр дүнгийн доод талын **Алгассан** жагсаалт нь зүйл бүрийг яагаад орхисныг нарийн хэлж өгнө.

**Nesting зураглал дээр хаалга эргэсэн байна — судал буруу болно.**
Группийг урд хавтан гэж танихаар нэрлэнэ (*Door*, *Front*, *Хаалга*, *Drawer front*), эсвэл нэрэнд нь `[G]` нэмнэ. Урд хавтан хэзээ ч эргэдэггүй.

**Материалын үнэ / хавтангийн хэмжээ буруу гарч байна.**
Деталь дээрх материалын нэр **Үнэ ба тариф → Хавтан материал** дахь нэртэй таарах ёстой. Зөв бичсэн эсэх, зузааныг шалгана уу.

**Ирмэг хуулга минь бодсоноос их гарч байна.**
Үүний нэг хэсэг нь **хуулсан тал бүрийн нөөц** (анхдагч 40 мм) бөгөөд ирмэг хуулах машины бодит хэрэглээг тусгадаг. Өртгийн задаргаанд тусдаа мөр болж харагдана. Таны машин өөр бол Нарийн тохиргоонд өөрчилнө.

**Зүсэлтийн өртөг буруу санагдаж байна.**
Зүсэлтийг деталиар биш, **хавтангаар** тооцдог. Материал бүр дээрх *Нэг хавтан зүсэх үнэ*-ийг шалгана уу.

**PDF буруу хэл / нэгжтэй гарч байна.**
Хэл: *Extensions → Panelwright → Хэл / Language*. Нэгж: *Нарийн тохиргоо → Нэгж*. Хоёулаа шинээр хийх бүх экспортод хамаарна.

**Өөрийн гэрээний текстийг ашиглаж болох уу?**
Болно — *Төсөл ба харилцагч → Гэрээний загвар*. `{% raw %}{{PROJECT}}{% endraw %}`, `{% raw %}{{AMOUNT}}{% endraw %}` гэх мэт орлуулах тэмдэгтүүд автоматаар бөглөгдөнө.

**OpenCutList / CutList Bridge-тэй хамт ажиллах уу?**
Тэдэнтэй зөрчилддөггүй, хоёуланг нь суулгаж болно. Panelwright нь задаргааны жагсаалтаас гадна шүүгээ үүсгэх, тоноглол, өрөмдлөг, өртөг, баримт бичгийг хамруулдаг.

**DXF минь CAM програм дээр жижигхэн геометртэй нээгдэж байна.**
DXF нь миллиметрээр. CAM програмынхаа импортын нэгжийг мм болгоно уу.

**Миний тохиргоо, үнэ хаана хадгалагддаг вэ?**
Үндсэн фолдер (*Төсөл ба харилцагч → Үндсэн фолдер*) дотор JSON файлаар, мөн SketchUp-ийн тохиргоонд нөөцтэй. **Нөөцлөлт** таб бүгдийг нэг файл руу экспортолно.

**Алдаа гарлаа.**
*Extensions → Panelwright → 🩺 Оношилгоо* → **Дэмжлэг рүү илгээх**. Алдаа гарах үед юу хийж байсанаа бичнэ үү.

**macOS: өргөтгөл идэвхжихгүй байна.**
*Extension Manager* нээж, Panelwright-ийг олоод *Enable* дарна. SketchUp-ийн ачаалах бодлого *Identified Extensions Only* бол өргөтгөл гарын үсэгтэй тул ачаалагдана; *Unrestricted* бол бүгд ачаалагдана.
