# Licence & activation

## Trial

10 days, every feature, no card. **Extensions → Panelwright → 🔑 License / Activate → Start trial.**

## Buying

https://extensions.sketchup.com/  (set after approval) — or https://panelwright.app.

One license = one computer at a time. Multi-seat packs for workshops with several stations: support@panelwright.app.

## Activating

1. Open **🔑 License / Activate**.
2. Copy the **Computer ID** shown there (looks like `4ARVE-TH2BR-…`).
3. If you bought through Extension Warehouse, your key is in your Trimble account. If you bought from us, send us the Computer ID and you'll get a key by e-mail.
4. Paste the key → **Activate**. Restart SketchUp once.

## Moving to another computer

Open the License window on the **old** computer → **Deactivate**. Then activate on the new one with the same key. If the old computer is dead, write to support with your order number and the new Computer ID.

## Offline computers

Activation itself is offline — the key is checked locally. You only need internet to *receive* the key by e-mail (any device will do), not on the workshop PC.

## Updates

Updates are included for 12 months from purchase. The plugin checks GitHub once a day (you can turn this off in *Advanced settings*) and offers a one-click install. **Extensions → Panelwright → 🔄 Check for updates** checks immediately.

## Something wrong?

**Extensions → Panelwright → 🩺 Diagnostics** → *Send to support*. The report contains version, environment and the last error — no company or customer data.
