Get your licence key

Your key is tied to one computer, so it is made after you install — not at checkout. This takes about a second.

  1. Install Panelwright — the .rbz came with your order e-mail. In SketchUp: Extensions → Extension Manager → Install Extension.
  2. Open Extensions → Panelwright → Licence, and copy the Computer ID shown there.
  3. Paste both below. Your key appears on this page — enter it in that same Licence window.
From your purchase e-mail — looks like 2C4A1B9E-7F3D-4A21-B8C6-9E1D5F0A3C7B.
From Extensions → Panelwright → Licence, inside SketchUp.

Changing computers? Use the same page on the new machine. If your seats are all used, write to support@panelwright.app and the old one is released. Lost your key? Enter the same two values again — you get the same key back, and it does not use another seat.
